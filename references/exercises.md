# Exercise selection

Pick the movement pattern first, then the tool the person actually has.

## Patterns to cover

A complete program hits each of these across the week:

| Pattern | Examples |
| --- | --- |
| Squat (knee-dominant) | Back/front squat, goblet, split squat, leg press, hack squat |
| Hinge (hip-dominant) | Deadlift, RDL, trap-bar, hip thrust, back extension, good morning |
| Horizontal push | Bench, DB press, push-up, machine chest press |
| Horizontal pull | Barbell/DB row, chest-supported row, seated cable row, inverted row |
| Vertical push | Overhead press, DB shoulder press, landmine press |
| Vertical pull | Pull-up, chin-up, lat pulldown, assisted pull-up |
| Loaded carry / core | Farmer's carry, plank, dead bug, pallof press, hanging leg raise |
| Single-leg | Lunge, split squat, step-up, single-leg RDL |

Missing a pattern for weeks creates the imbalances people later call "injuries."
Single-leg and hinge are the most commonly skipped.

## Equipment substitution ladder

Same pattern, descending equipment. Walk down until you hit what they own.

**Squat:** back squat → front squat → goblet squat → DB split squat → Bulgarian
split squat → bodyweight squat → sissy squat / wall sit

**Hinge:** conventional deadlift → trap-bar → RDL → DB RDL → hip thrust →
single-leg RDL → back extension → glute bridge → Nordic curl (eccentric)

**Horizontal push:** barbell bench → DB bench → machine press → weighted
push-up → push-up → incline push-up → band press

**Horizontal pull:** barbell row → DB row → chest-supported row → seated cable
row → inverted row → band row → towel row on a door

**Vertical pull:** weighted pull-up → pull-up → assisted pull-up → lat pulldown
→ band pulldown → inverted row at steep angle

**Vertical push:** standing OHP → seated DB press → landmine press → pike
push-up → handstand progression

Rule: **change the tool before you drop the pattern.** "No barbell" almost never
means "no squatting."

## Bodyweight-only programming

Entirely viable for hypertrophy and endurance; limited for maximal strength
once someone is strong.

Progress by: reps → tempo (3–4 s eccentric) → range of motion → leverage
(incline → flat → decline → single-limb) → unilateral → added load (backpack).

Weak spots to plan around: hinge/hamstrings (use Nordics, single-leg RDL, glute
bridges) and vertical pull (needs a bar — a sturdy door frame bar is the single
highest-value purchase).

## Technique cues

One or two cues per exercise. More than that and nobody remembers any of them.

| Exercise | Cues |
| --- | --- |
| Back squat | Brace before descending; knees track over toes; chest stays up through the drive |
| Deadlift | Bar over midfoot; lats engaged ("protect your armpits"); push the floor away |
| Bench press | Shoulder blades retracted and down; feet planted; bar to lower chest; wrists stacked |
| Overhead press | Squeeze glutes to stop the lean; head moves through at lockout |
| Row | Pull to the lower ribs, not the neck; lead with the elbow; no torso swing |
| Pull-up | Start from a dead hang; drive elbows to the pockets; full ROM over extra reps |
| RDL | Push hips *back*, soft knees; stop where the hamstrings run out, not the floor |
| Hip thrust | Ribs down, chin tucked; pause at the top; don't hyperextend the low back |
| Split squat | Torso tall; weight through the front heel; back knee tracks down |
| Lateral raise | Lead with the elbow; stop at shoulder height; it's light on purpose |

For beginners add: "Control the lowering — that's where most of the growth
comes from, and it's the half everyone rushes."

## Selection rules

1. **Compounds first**, when fresh. Isolation after.
2. **Match the goal.** Strength needs loadable, repeatable, measurable lifts.
   Hypertrophy tolerates machines and cables happily — stability isn't the
   limiter you want.
3. **Respect preferences.** A liked exercise done for a year beats an optimal
   one abandoned in a month. If they hate back squats, program a different
   knee-dominant movement and say why that's fine.
4. **Limit novelty.** Keep the main lifts stable for a block so progression is
   measurable. Rotate accessories, not the lifts you're tracking.
5. **Budget the time.** ~3–4 min per working set including rest for compounds.
   Four exercises × 3 sets ≈ 40 min plus warm-up. Do that arithmetic before
   writing the session.
6. **Give one alternative per exercise** in the plan — for a busy gym, a
   missing machine, or a bad joint day. This single habit prevents most
   skipped sessions.
