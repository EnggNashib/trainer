# Code of conduct

## The short version

Be decent. Critique code and ideas, not people. Assume the person on the other
end is trying to help.

## Not welcome

Harassment, personal attacks, demeaning comments about anyone's body, weight,
strength, ability or health, sustained disruption, or publishing someone's
private information. Fitness spaces have a particular habit of the body-shaming
variety — it isn't tolerated here, in issues, pull requests or commit messages.

## Scope

This applies in every space connected to the project, and when representing the
project elsewhere.

## Enforcement

Report a problem to **engg.nashib@gmail.com**. Reports stay confidential.

Maintainers will respond with whatever is proportionate: a warning, deleting the
offending content, or blocking the account. Maintainers who don't follow this
themselves should be reported the same way and are not exempt.

Adapted loosely from the [Contributor Covenant](https://www.contributor-covenant.org),
kept short deliberately — a code of conduct nobody reads protects nobody.
